# HUBBI — Frozen Heights ❄

Браузерная 3D-игра — копия горнолыжного мини-мира **Frozen Heights** из Hubbi World.
Чистый Three.js (через CDN import-map), без сборки: открывается прямо в браузере.

## Запуск
```bash
npx serve .        # или любой статический сервер
# затем открой http://localhost:3000
```
Можно и GitHub Pages: Settings → Pages → branch `main` / `(root)`.

## Управление
| Клавиша | Действие |
|---|---|
| WASD | движение (в воздухе A/D — вращение для трюков) |
| Мышь | камера (Pointer Lock) |
| Пробел | прыжок |
| Shift | спринт (тратит выносливость) |
| F | присесть (быстрее скользишь по склону) |
| Q | рывокdash |
| Esc | выход в меню |

## Механики
- Процедурный заснеженный склон с уклоном, скольжением и градиентом
- Монетки 🪙 и кристаллы 💎 по всей трассе (респаун каждые 3 мин)
- Трюки в воздухе: спины дают XP; жёсткие посадки и столкновения — урон HP
- Уровни, XP, магазин скинов и улучшений (сохранение в localStorage)
- Канатная дорога, ёлки, домики курорта, снеговики, флажки трассы, метель

## Структура
```
index.html          — экраны меню/магазина/HUD + importmap three@0.160
src/main.js         — сцена, свет, цикл, камера от третьего лица
src/core/input.js   — клавиатура + pointer lock
src/core/storage.js — сохранения, экономика, уровни
src/world/terrain.js— склон, деревья, камни, хаты, кресёлка
src/world/snow.js   — партиклы снега
src/entities/player.js  — хабби-персонаж и физика
src/entities/pickups.js — собираемые монеты/кристаллы
src/ui/hud.js, style.css — интерфейс
```
